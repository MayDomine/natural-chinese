# 好好说话.skill

一个 Claude Code Skill，让 AI 用自然、像人的中文表达，去掉满屏的"AI 腔"——对仗套话、空洞大词、情绪金句、中英文乱混。

## 解决什么问题

GPT、Claude 这些模型写中文时爱用一套可预测的模板：动不动"不是 A 而是 B"、"综上所述"、"赋能/闭环/抓手"、"狠狠接住"，再随手夹几个 strawman / scope / drop-in。这些表达的共同毛病是**用模板替代具体内容**——删掉形容词副词就什么都不剩，还能原样套到别的话题上。

这个 skill 把这些毛病归成几类，给出可操作的判据和替换方法，让模型在写中文前自查。

## 覆盖的 AI 腔

| 类型 | 例子 | 怎么改 |
|------|------|--------|
| 句式套路 | 不是…而是、首先其次、综上所述 | 看逻辑关系，并列才用排比 |
| 空洞大词 | 赋能、助力、闭环、深远影响、抓手 | 换成谁做了什么、数字多少 |
| 情绪金句 | 狠狠接住、稳稳拿捏、情绪价值拉满、破防 | 说清具体发生了什么 |
| 中英文乱混 | strawman、scope 到 X、drop-in、gate | 有通行中译就用中文 |

核心判据：**这个词/这句话有没有通行的中文说法？删掉修饰还剩信息吗？能不能套到别的话题上？**

## 安装

把 `natural-chinese/` 放进 skills 目录即可：

```bash
git clone git@github.com:MayDomine/natural-chinese.git ~/.claude/skills/natural-chinese
```

之后在中文写作、回复、总结、润色场景下，Claude 会按 `description` 自动加载它。

## 用法

无需手动触发。skill 的 `description` 写明了适用场景（中文写作/回复/总结/润色/文档），排除了代码和命令，模型在写面向人的中文时会自动参考。也可以显式 `/natural-chinese` 调用。

## 说明

规则不是死的。比如排比——并列的几件事用排比没问题，只有把因果/转折硬塞进排比壳里才算 AI 腔；中英文混杂也允许保留没有公认中译的术语（FSDP、all_gather 这种）。分寸都写在 `SKILL.md` 里。
